## 📜 Descrição

Este repositório contém o projeto desenvolvido para a disciplina MC613 - Laboratório de Circuitos Digitais da Universidade Estadual de Campinas (Unicamp). O objetivo do projeto foi aplicar os conhecimentos adquiridos em aula sobre metodologia de projeto digital, lógica combinacional e sequencial, máquinas de estado e descrição de hardware em Verilog para projetar, simular e implementar sistemas digitais: ULA, Multiplicador Multiciclo, Relógio Digital...

## 🛠️ Ferramentas Utilizadas

*   **Linguagem de Descrição de Hardware (HDL):** Verilog
*   **Software de Síntese e Implementação:** Quartus Prime
*   **Placa de Desenvolvimento/FPGA:** DE1-SoC
